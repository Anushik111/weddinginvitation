# Aram & Armina — Wedding Invitation

## GitHub-ում տեղադրելու ձևը
1. Այս ZIP-ը բացիր համակարգչիդ մեջ։
2. GitHub-ի repository-ում վերբեռնիր `index.html` ֆայլը և ամբողջ `images` պանակը։
3. GitHub Pages-ը միացնելուց հետո հրավիրատոմսը կբացվի կայքի հղումով։

## Նկարները փոխելը
`images` պանակում փոխիր նկարը՝ նույն անունով նոր նկար վերբեռնելով (Replace file)։ Կոդը խմբագրելու կարիք չկա։
- `bride-home.jpg` — հարսի տուն
- `groom-home.jpg` — փեսայի տուն
- `church.jpg` — եկեղեցի
- `restaurant.jpg` — ռեստորան
- `gallery-1.jpg`, `gallery-2.jpg` — սահիկի նկարներ
- `floral-cover.jpg` — վերևի ծաղկային ֆոն
- `floral-section-background.jpg` — էջի ծաղկային ֆոն

Նկարները պահիր JPG ձևաչափով և օգտագործիր ճիշտ նույն ֆայլի անունը։ Նոր նկար վերբեռնելիս GitHub-ում ընտրիր նույն անունով ֆայլը և հաստատիր փոխարինումը։
